# Critique pass

Run after every render, on the images from `kit/checks.sh`, not from memory of the code.
You are a harsh director seeing this for the first time. You did not make it.

1. **Ask the review questions first:** who is this for, what is it communicating, and does each element need to be there?
2. **Score 1–10, each with one line of evidence and a timestamp:**
   - Hook: do the first 2 seconds earn the next 10?
   - Phone: does every frame read at 360 px wide?
   - Clarity: does each scene teach one thing the viewer can now say?
   - Motion: one personality, eased, three layers, exits shorter than entrances, one focal action at a time?
   - Variety: something new every 2–4 seconds, no dead beats?
   - Composition: a clear hero in every frame; safe areas respected?
   - Brand: palette, type and motifs only from BRAND.md?
   - Sound: do cues land on the moves; is the voice clear over the music? Check it muted and audio-only.
   - Access: 4.5:1 contrast, no flashes above 3 per second, colour never the only signal.
3. **List the three worst problems,** each with the timestamp and the fix.
4. **Fix only those,** re-render only those seconds, show a before/after frame for each, and run this again.
5. **Stop when every score is 8 or more** and the hard gates pass: determinism, loop seam, loudness, fonts.
